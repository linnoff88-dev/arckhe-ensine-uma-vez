In a nutshell

Ensine Uma Vez is a kit for turning a conversation that went well into a procedure AI can repeat. It is for people who still explain the same task every week and want to start delegating it. You save the corrections, test the procedure with a new case, and decide when you can stop reviewing every deliverable. Use it with Claude Code or Codex and a task you have already completed with AI.

See the same meeting at all five levels

AL1

You do the work

You read the notes and write the list of next steps on your own.

AL2

AI helps

The chat suggests a summary template. You put the action items in the document.

AL3

The agent works with you

Give it access to the notes and guide the first deliverable. Correct what is missing. In this example, every action needs an owner and a deadline.

AL4

The agent prepares it; you review

Save the procedure the AI will follow, also called a skill. Use new notes and check that the table has one action per row, with a confirmed owner and deadline. When you adjust the rule, rerun the case that failed. Save the rule “every action needs an owner.” The detail “Ana sends this invitation” applies to that meeting.

AL5

The routine runs and calls you when needed

The test saves the table or notice in the results folder. To run it at work, configure the schedule, the limits on what the agent can do, and how to notify the owner.
